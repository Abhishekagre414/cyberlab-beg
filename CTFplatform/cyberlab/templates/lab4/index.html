Objective

This file portal lets you download files from a public folder via /lab4/download?file=<name>. There's more than one folder sitting next to the public one — only one of them actually matters. Get the flag out of it.

{% if mode != 'challenge' %}
Why this happens in the real world

The download endpoint tries to defend itself by stripping the sequence ../ out of your filename before using it. A filter that only runs once, and only looks for one exact pattern, can often be defeated by input that doesn't contain that pattern yet, but produces it once the filter has already run.

Where to start
  • Confirm the filter exists first: a plain traversal attempt just quietly does nothing.
  • Read the public files carefully — team notes sometimes casually mention things (folder names, tools, people) that turn out to matter later. That's true in this lab too.
  • Once you get past the filter, don't assume the first sibling folder you find is the right one.
