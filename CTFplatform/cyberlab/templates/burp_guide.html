Using Burp Suite with these Labs

A beginner-friendly walkthrough for pointing an intercepting proxy at this local training environment.

⚠️ Scope reminder

Only ever point Burp Suite (or any proxy/scanner) at systems you own or have explicit written permission to test — that includes this local lab, running on your own machine, and nothing else. Never aim these tools at real, third-party websites.

Step-by-step
  1. Start Burp Suite. Launch it and create (or open) a temporary project.
  2. Configure the browser proxy. Point your browser's proxy settings (or use a dedicated browser profile / FoxyProxy) at Burp's listener — by default 127.0.0.1:8080.
  3. Enable interception. In Burp's Proxy tab, turn "Intercept is on" so requests pause before being sent.
  4. Visit the local CyberLab. Browse to http://127.0.0.1:5000 through your proxied browser.
  5. Observe HTTP requests. Watch each request pass through Burp's Proxy → HTTP history. Notice headers, cookies, and form data.
  6. Send requests to Repeater. Right-click an interesting request (e.g. the Lab 2 login POST) and choose "Send to Repeater" to replay and tweak it freely.
  7. Modify parameters or cookies — only within this local lab. Try editing the x_client_user_id cookie for Lab 3, or the username/password fields for Lab 2.
  8. Analyze the response. Compare what changed in the response body/status code after your edit — that's the core skill this whole workflow is teaching.
Which labs pair well with Burp?
  • Lab 1 — inspect the Authorization: Basic ... header once you've got Basic Auth credentials.
  • Lab 2 — use Repeater to iterate on SQL injection payloads quickly without retyping the form each time.
  • Lab 3 — edit the x_client_user_id cookie directly in a resent request.
  • Lab 4 — try different file query parameter values in Repeater.
  • Lab 5 — send different YAML payload bodies without re-typing the textarea each time.
Don't have Burp Suite?

Your browser's built-in DevTools (Network tab + Application/Storage → Cookies) can do almost everything above for these labs — that's intentional, so nobody is blocked from any lab by tooling.
